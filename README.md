# Cartão NFC

## Arquivos
| Arquivo | Para quê |
|---|---|
| `dados.js` | **Seus dados** — o único arquivo que você precisa editar |
| `index.html` | Estrutura da página |
| `style.css` | Visual |
| `app.js` | Monta o cartão a partir do `dados.js` |

## Publicar (GitHub Pages)
1. Envie os arquivos para o repositório `cartao_nfc`.
2. **Settings → Pages → Branch: main / (root) → Save**.
3. Link: `https://SEU-USUARIO.github.io/cartao_nfc/`

## Gravar na NFC
App **NFC Tools** → Escrever → Adicionar registro → **URL** → cole o link → Escrever.
